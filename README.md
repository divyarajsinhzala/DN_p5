# Experiment 5 - Academic Calendar & Leave Management System

ASP.NET Web Forms (.NET Framework 4.8) project using rich controls (Calendar, DropDownList), Session and Cookies.

Author: Divyarajsinh Zala (92400103539), Batch B

## Run
1. Open `WebApplication1.sln` in Visual Studio 2019/2022 (with the "ASP.NET and web development" workload).
2. Press F5. The start page is `WebForm1.aspx` (login). Enter any name and password.
3. Pick a leave type and date on `Leave.aspx`, then click Apply Leave.
